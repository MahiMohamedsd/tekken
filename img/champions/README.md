# Champion pictures

Drop one picture per champion in this folder, named by its slug. `.webp`, `.png` and `.jpg` all work.
Portrait shapes (about 3:4) look best. Any champion without a picture gets a styled monogram card instead.

Example: `img/champions/jin.png`, `img/champions/devil-jin.webp`.
To add a new champion, add the name to the `CHAMPIONS` list near the top of the script in `index.html`.
